HOW TO RUN
----------
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server, or open index.html directly in Chrome.
4. Tap the gift.
5. Enter 1234.
6. The floral page appears for about 2.4 seconds, then the main page opens.

CHANGE PASSKEY
--------------
Open script.js:
const PASSKEY="1234";
